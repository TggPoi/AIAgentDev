# Node.js 内置测试运行器 node:test 适用场景

## 功能特点与优势

Node.js 22+ 内置的 `node:test` 测试运行器具有以下核心优势：

- **零配置**：无需安装额外依赖，使用 `node --test` 即可自动扫描并运行测试文件
- **启动速度快**：直接在 Node.js 进程中运行，无需转译，冷启动时间几乎为零
- **稳定性高**：作为 Node.js 核心库的一部分，不存在版本不兼容问题
- **原生支持 Mock 与覆盖率**：内置深度 Mock 机制和代码覆盖率功能

## 小型 JavaScript CLI 项目的 3 个适用场景

### 场景 1：快速原型验证与单元测试

**说明**：在开发 CLI 工具的初期阶段，需要频繁验证核心功能逻辑的正确性。`node:test` 无需安装和配置任何外部测试框架，开发者只需创建测试文件并运行 `node --test` 即可立即执行测试。这对于快速迭代的原型项目尤其适合，能够减少项目依赖，保持代码库轻量。

### 场景 2：CI/CD 流水线中的自动化测试

**说明**：小型 CLI 项目通常需要在持续集成环境中自动运行测试。`node:test` 作为 Node.js 内置模块，无需在 CI 环境中额外安装测试依赖，减少了构建时间和镜像体积。其标准化的输出格式便于与 CI 工具集成，且启动速度快能够显著缩短流水线执行时间。

### 场景 3：函数 Mock 与依赖隔离测试

**说明**：CLI 工具常涉及文件系统操作、网络请求等外部依赖。`node:test` 内置的 Mock 机制允许开发者轻松模拟这些依赖，实现真正的单元测试隔离。例如可以 Mock `fs` 模块测试文件处理逻辑，或 Mock HTTP 请求测试网络功能，而无需引入 sinon 等第三方 Mock 库。
