# 角色美术风格规范

## 文档目的

本文档用于定义当前 Agent RAG 测试项目中的角色美术风格规范，主要面向 **美术部门 art** 使用。

该文档适用于以下内容的设计与评审：

* 角色概念设计
* 像素角色 Sprite
* 角色立绘
* 战斗演出图
* UI 头像
* 动画参考图
* 技能展示中的角色姿态

本项目的角色美术目标是：

> 角色需要具有清晰的轮廓、温暖的色彩、明确的性格表达，并且符合轻幻想冒险题材。

本文档属于美术部门内部知识库内容。非 art 部门用户在权限过滤正确的情况下，不应该检索到本文档内容。

---

## 1. 整体美术方向

项目采用 **轻幻想冒险风格**。

角色不追求完全写实，而是更强调：

* 轮廓清晰
* 情绪表达明确
* 颜色温暖
* 装备和服装具有辨识度
* 小尺寸下仍然可读
* 适合在 UI、像素 Sprite、立绘之间保持统一

推荐的视觉关键词：

```text
温暖
柔和
清晰
轻幻想
手绘感
角色性格明确
细节克制
轮廓优先
```

需要避免的方向：

```text
过度写实
颜色灰暗
盔甲细节过多
面部阴影过重
恐怖风格渲染
赛博朋克高对比霓虹光
头部和手部附近出现过多视觉噪声
```

角色设计的首要目标不是“细节最多”，而是“玩家第一眼能记住”。

---

## 2. 角色轮廓规范

所有主要角色都必须具有清晰轮廓。

判断标准是：

> 如果角色被处理成纯黑剪影，玩家仍然应该能大致分辨这个角色是谁。

设计轮廓时，优先关注：

1. 头部形状
2. 发型外轮廓
3. 肩部和披风形状
4. 武器或工具形状
5. 标志性饰品形状

例如：

* 女巫角色可以通过宽帽檐、扫帚、披风边缘形成轮廓记忆点。
* 骑士角色可以通过宽肩甲、短披风、剑柄形成轮廓记忆点。
* 学者角色可以通过长袖、书本、单肩包形成轮廓记忆点。
* 盗贼角色可以通过不对称披风、短刃、低重心姿态形成轮廓记忆点。

需要避免多个主要角色拥有相似的头部轮廓和披风轮廓。

---

## 3. 面部与表情规范

角色面部需要在小尺寸下保持可读。

眼睛区域是表情表达的核心。即使是像素风格，也需要通过眼睛、眉毛、嘴角表达清楚情绪。

常用表情处理方式如下：

| 情绪 | 表现方式           |
| -- | -------------- |
| 平静 | 眉毛放松，眼神稳定，嘴角自然 |
| 好奇 | 眉毛略微抬起，眼睛更圆    |
| 自信 | 眉毛略有角度，嘴角轻微上扬  |
| 疲惫 | 上眼睑下压，嘴部放松     |
| 生气 | 眉毛向内压，嘴部收紧     |
| 惊讶 | 眼睛放大，嘴部变小或微张   |

面部细节不应过度复杂。

需要避免：

* 牙齿细节过多
* 鼻梁渲染过重
* 法令纹过强
* 阴影让表情变得阴沉
* 小尺寸下眼睛无法识别

---

## 4. 肤色与暖色倾向

角色肤色应具有健康的暖色倾向。

即使角色设定为肤色较浅，也不应呈现灰白、死白或缺乏生命感的效果。

建议使用以下倾向：

* 浅肤色：加入轻微桃色或粉色
* 中等肤色：加入暖棕或橙粉倾向
* 深肤色：保持饱和度和暖调，避免阴影发灰

阴影区域不要直接使用纯灰色。可以使用：

```text
低饱和玫瑰色
暖棕色
偏紫的暗部色
低饱和红棕色
```

需要特别注意的区域：

* 面部
* 手部
* 耳朵
* 膝盖
* 小腿
* 手指关节

这些区域可以加入轻微暖色，让角色更有生命感。

---

## 5. 发型设计规范

发型应服务于角色识别。

发型设计优先考虑大形状，而不是一开始就画大量发丝。

推荐流程：

1. 先确定发型整体轮廓。
2. 再划分主要发束。
3. 添加有限数量的高光组。
4. 最后只在必要位置补少量发丝。

需要避免：

```text
发丝过密
高光过碎
头部轮廓不清
头发遮挡表情
小尺寸下发型变成噪声
```

如果角色具有魔法属性，头发可以有轻微漂浮感，但不能影响面部识别。

---

## 6. 服装设计规范

角色服装需要表达职业、性格和世界观。

每个角色建议只有一个主要服装主题，并搭配一到两个辅助设计元素。

示例：

| 角色类型 | 服装关键词           |
| ---- | --------------- |
| 女巫   | 长袍、宽帽檐、扫帚、月亮吊坠  |
| 工程师  | 短外套、工具腰带、手套、金属扣 |
| 学者   | 长袖、书包、书本、护符     |
| 守卫   | 披风、肩甲、腰带、徽记     |
| 游侠   | 围巾、长靴、皮革绑带、叶形饰品 |

服装设计要避免无意义堆叠。

好的角色服装通常来自：

```text
清晰轮廓 + 统一主题 + 少量高质量细节
```

细节应集中在视觉焦点区域：

* 面部附近
* 胸口饰品
* 手部动作
* 武器或工具
* 腰部关键装饰

大面积留白是允许的。留白可以提升角色可读性。

---

## 7. 角色配色规范

每个主要角色建议使用三层颜色结构：

```text
主色
辅助色
强调色
```

示例：

```text
主色：深紫色
辅助色：暖棕色
强调色：月光金色
```

强调色应少量使用，通常放在：

* 眼睛
* 饰品
* 魔法效果
* 武器细节
* UI 头像高光点

需要避免：

```text
所有部位都高饱和
主色不明确
强调色使用面积过大
不同角色之间配色过于相似
```

如果角色身上所有地方都很抢眼，那么玩家反而无法判断哪里重要。

---

## 8. 像素 Sprite 规范

像素 Sprite 的核心原则是：

> 清晰度优先于细节数量。

Sprite 制作要求：

* 使用清晰色块
* 避免单像素噪点
* 保持头部和手部可读
* 不要过度抗锯齿
* 保持武器或工具轮廓清晰
* 不要在不同动画帧中改变角色核心轮廓

Sprite 中最重要的区域：

1. 头部
2. 手部
3. 武器或工具
4. 脚部接地点
5. 头发和披风的运动

动画中需要体现二级运动：

```text
身体先动
头发随后动
披风略微延迟
饰品最后跟随
```

这样可以让角色动作更自然，也更有重量感。

---

## 9. 角色动画性格规范

角色动画应体现性格差异。

勇敢角色可以表现为：

* 站姿稳定
* 肩部打开
* 动作直接
* 预备动作较短

害羞角色可以表现为：

* 肩膀内收
* 手部动作较小
* 视线变化较慢
* 身体重心略微后缩

调皮角色可以表现为：

* 头部转动更快
* 手部动作更活跃
* 站姿不对称
* 披风或头发有更明显弹性

不要让所有角色使用相同节奏的 idle 动画。即使只调整几帧停顿时间，也能明显改变角色性格。

---

## 10. 光照规范

默认角色光照方向为：

```text
左上方主光
右下方柔和暗部
必要时添加轻微暖色轮廓光
```

普通角色立绘不建议使用强烈下方光源，因为这容易产生恐怖感。

战斗演出图可以使用更强烈的光影，但必须保证面部可读。

魔法光源需要影响周围材质：

* 发光法杖应轻微照亮手部
* 魔法书应给脸部下方一点光
* 火焰技能应让袖口和手部偏暖
* 冰系技能应让暗部边缘偏冷

不要把魔法光简单叠在角色上，而不影响周围物体。

---

## 11. 材质表现规范

不同材质需要通过明暗和边缘处理区分。

| 材质   | 表现方式       |
| ---- | ---------- |
| 布料   | 柔和褶皱，低反光   |
| 皮革   | 褶皱更硬，高光较窄  |
| 金属   | 高对比，边缘高光清晰 |
| 头发   | 成组高光，顺着发流  |
| 皮肤   | 过渡柔和，暖色暗部  |
| 魔法晶体 | 内部发光，高对比边缘 |

不要让所有材质使用同一种高光方式。

---

## 12. 角色评审清单

角色设计提交前，需要检查以下问题：

* 角色剪影是否清晰？
* 小尺寸下是否能看清脸？
* 主色是否明确？
* 细节是否集中在重点区域？
* 服装是否表达了角色身份？
* 手部和关键道具是否清楚？
* 是否符合轻幻想冒险风格？
* Sprite 和立绘是否保持同一角色识别？
* 肤色是否有足够暖色？
* 暗部是否避免发灰？
* 是否存在无意义的视觉噪声？

如果以上问题中有三项以上不通过，角色设计应退回修改。
