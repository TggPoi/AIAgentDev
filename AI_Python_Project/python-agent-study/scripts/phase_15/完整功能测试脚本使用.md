# 完整功能 Web 验收说明

原交互式 CLI 测试脚本已经删除。完整登录、多轮对话、结构化 SSE、TaskPlan 查看与确认统一使用：

```text
scripts/phase_15/rag_agent_manual_acceptance.html
```

## 启动验收页面

在仓库根目录启动一个静态文件服务：

```powershell
.\.venv\Scripts\python.exe -m http.server 5173 --directory scripts\phase_15
```

浏览器打开：

```text
http://127.0.0.1:5173/rag_agent_manual_acceptance.html
```

页面用于验证：

```text
/auth/login
/auth/me
/rag/chat
/rag/chat/stream/events
多轮 session_id
Prompt Guard 事件
TaskPlan 读取与人工确认
NL2SQL Dataset 与 action
```
