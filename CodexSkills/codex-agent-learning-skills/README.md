# Codex Agent Learning Skills

This package contains Codex skills generated from the current AI Agent / RAG learning conversation.

## Install in a repository

Copy the `.agents/skills` directory into your project root:

```text
your-repo/
  AGENTS.md
  .agents/
    skills/
      agent-tutorial-study-coach/
      code-dataflow-explainer/
      rag-debugging/
      graphrag-cypher-generation/
      agent-skill-design-review/
```

## Install globally

You can also copy each skill directory into your global skills directory:

```text
~/.agents/skills/
```

## Suggested AGENTS.md entry

This package includes an `AGENTS.md` you can copy into your repository root or merge into your existing AGENTS.md.

## Included skills

1. `agent-tutorial-study-coach`
   - Use when learning AI Agent tutorial chapters or asking for chapter breakdowns.

2. `code-dataflow-explainer`
   - Use when explaining unfamiliar code, especially TypeScript / Node.js / Nest / LangChain / LangGraph code.

3. `rag-debugging`
   - Use when diagnosing RAG, ES, Milvus, rerank, retrieval, or hallucination problems.

4. `graphrag-cypher-generation`
   - Use when generating, reviewing, or debugging Neo4j Cypher and GraphRAG workflows.

5. `agent-skill-design-review`
   - Use when designing or reviewing Agent Skills.
